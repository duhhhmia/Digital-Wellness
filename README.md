# **Instagram User Well-Being Analysis**

## 📋 Project Overview
As part of a simulated engagement for **Instagram's User Well-Being Team**, this project analyzes how daily active screen time impacts the mental health of young adults (ages 20–35) in the United States. Using data-driven insights, the goal is to design product features that balance platform engagement with user digital wellness.

## ❓ Business Problem & Hypothesis
* **Core Question:** For users in the U.S. aged 20–35, how do daily active minutes affect overall mental health scores based on the 2025 Digital Wellness Report?
* **Objective:** Identify the "tipping point" where increased screen time negatively impacts user sentiment, allowing the product team to introduce proactive wellness interventions.

## 🛠️ Tech Stack & Dataset
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Dataset:** 2025 Digital Wellness Report (U.S. Demographic Slice)

## 💡 Strategic Product Recommendations
Based on the data trends, the following features are proposed for the Instagram Q1/Q2 roadmap to support user longevity and health:
* **Time Management Tools:** Implement contextual in-app nudges and customizable daily limits when users approach the identified threshold.
* **Wellness Resources & Coaching:** Integrate native mental health checks and resource hubs directly into the user interface.
* **Influencer Partnership Program:** Collaborate with platform creators to promote healthy scrolling habits and digital boundaries.
